# Shop icon

Finished art for the Home header's Shop button (Figma: node `277:1891`,
file `Joanx`). Replaces the drawn lucide `Icon name="shopping-bag"` used
for the "go to the egg shop" entry point.

Served at `/assets/shop/<file>`. Wired via `ShopIcon` in
`src/core/primitives.jsx` (see `PointIcon` for the same pattern).

| File | Used for |
| ---- | -------- |
| `shop-stall.png` | Shop button icon (Home header) — `ShopIcon` |
| `figma-reference-header.png` | Design reference only, not loaded by the app — a screenshot of the Figma header (node `277:1891`) this button was matched to. |
